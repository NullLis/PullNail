PullNail《积木与钉子》个人信息保护说明

最后更新日期：2026年11月3日

引言与适用范围

欢迎使用 PullNail《积木与钉子》（以下简称“本游戏”）。本游戏由 NullLis 开发。本隐私政策适用于本游戏及其相关介绍、下载与支持网站（以下简称“相关网站”），用于说明相关服务可能涉及的个人信息处理活动及您享有的权利。

本游戏以单机关卡玩法为主，您无需为了体验基本单机玩法而主动提交姓名、手机号码等身份信息。但在使用网络配置、访问网站或联系开发者时，仍可能发生必要的网络信息处理。

我们遵循合法、正当、必要和透明的原则处理个人信息，并按照适用法律法规履行相关义务。不同发行渠道或版本如有额外功能，相关个人信息处理规则应以实际提供的功能及相应告知为准。

1. 我们可能收集的个人信息

根据您使用的具体功能，可能涉及以下信息：

  • 本地游戏数据：关卡进度、游戏设置及其他用于恢复游戏状态的数据可能保存在您的设备本地。本地保存并不意味着我们会自动读取或上传这些数据。
  • 网络访问与基础日志：当本游戏检查远程配置、版本信息，或您访问相关网站时，网络通信及托管服务可能处理 IP 地址、请求时间、访问路径、浏览器或设备类型等信息，以完成连接、交付内容和维护安全。
  • 主动提交的信息：如您通过电子邮件或 GitHub Issues 联系我们，我们可能处理您提供的邮箱地址、问题描述、截图及其他反馈资料，以便回复和解决问题。请勿在公开反馈页面发布敏感个人信息。

我们不会仅为了提供基本单机玩法而要求您提交与玩法无关的身份信息。如未来的客户端版本实际启用广告、第三方登录、统计分析或崩溃上报等涉及额外数据处理的功能，我们将按实际情况进一步说明所涉数据、使用目的、服务方及必要的选择方式；本段不构成对任何未披露数据处理的授权。

2. 我们如何使用您的个人信息

在确有必要且具有适当处理依据的情况下，我们可能将相关信息用于：

  • 提供和维护游戏的基本功能、配置获取与版本信息服务；
  • 排查连接故障，保障游戏和相关网站的稳定性及安全性；
  • 处理您主动提交的反馈、咨询和个人信息权利请求；
  • 履行适用法律法规规定的义务。

我们不会将您主动提供的联系信息用于与上述目的无关的营销，也不会出售您的个人信息。若处理目的或方式发生实质变化，我们将依法履行进一步告知、征求同意等必要程序。

3. 我们如何存储和保护您的个人信息

存储位置与期限：本地游戏数据通常保存在您的设备上，直到您删除相关数据、清除应用存储或卸载应用；具体结果亦可能受到设备备份机制的影响。网站访问日志可能由 GitHub Pages、Cloudflare Pages 等服务提供方按照其规则保存。对于您主动发送的反馈信息，我们将在处理问题及履行必要义务所需的期限内保存，并在不再需要时依法删除或进行适当处理。

安全措施：我们将根据实际处理活动采取合理的访问控制、传输保护和数据最小化措施，尽力防止信息遭到未经授权的访问、泄露、篡改或丢失。但任何网络和存储技术均无法保证绝对安全。

若您希望了解特定反馈信息的保存和删除情况，可通过本政策第 9 章的联系方式向我们提出请求。

4. 我们如何对外提供您的个人信息

我们不会以出售个人信息为目的向第三方提供您的数据。为实现网站访问、远程配置获取及问题反馈等功能，必要的数据可能由下列服务提供方按照各自的规则处理：

  • GitHub：用于项目托管、GitHub Pages 网站和 GitHub Issues 问题反馈。请参阅 GitHub 隐私声明。
  • Cloudflare：用于相关网站及远程配置资源的交付。请参阅 Cloudflare 隐私政策。

如果某个游戏发行版本另行接入广告、登录或其他第三方 SDK，相关服务方可能独立处理其提供服务所需的信息。我们将根据该版本的实际接入情况补充服务方名称、数据类型、使用目的和隐私政策链接；上述说明不代表我们已经接入任何特定广告或登录 SDK。

除依法要求、获得适当授权或提供服务确有必要的情形外，我们不会随意共享、转让或公开披露您的个人信息。相关网站的服务提供方可能在不同国家或地区处理网络访问数据；涉及适用法律要求的跨境处理时，我们将履行相应义务。

5. 我们如何使用Cookies及相关技术

Cookie 是网站可能存储在浏览器中的小型数据文件。目前，相关网站页面不主动通过 Cookie 对访问者开展跨站广告追踪或个性化画像。

浏览器、网站托管平台或您主动访问的第三方链接仍可能使用 Cookie、缓存或其他必要技术，以维护安全、交付页面或记住有关设置。其具体使用情况受相关服务提供方的规则约束。

您可以在浏览器设置中查看、限制或清除 Cookie。禁用某些必要技术可能影响网页的正常显示或功能。本游戏的本地关卡存档不属于网页 Cookie。

6. 我们如何保护未成年人的权益

我们重视未成年人的个人信息保护。如果您是未成年人，请在监护人的指导下阅读本政策，并根据适用法律法规取得必要的监护人同意。

我们不会以主动收集未成年人的敏感个人信息作为基本单机玩法的前提。若某项功能确需处理未成年人的个人信息，我们将根据适用的年龄标准、处理目的和法律要求采取相应保护措施。

如监护人认为未成年人的个人信息被不当处理，可通过本政策第 9 章联系我们，我们将核实并依法处理。

7. 您对个人信息享有的权利

在适用法律规定的范围内，您可能享有知情、访问、复制、更正、删除、限制或拒绝处理，以及撤回同意等权利。

  • 管理本地数据：您可以通过设备系统提供的功能清除应用数据或卸载游戏。此操作可能使尚未备份的游戏进度无法恢复。
  • 管理主动提交的信息：如您通过邮件提交了个人信息，可联系我们申请查询、更正或删除。通过 GitHub Issues 公开发布的信息也可能受 GitHub 平台的内容管理规则约束。
  • 撤回同意：对于以您的同意为依据的个人信息处理活动，您可按相应功能提供的方式撤回同意；撤回通常不影响此前依法进行的处理。

我们会核实请求并根据适用法律在合理期限内答复。对于依法无法直接处理的第三方平台数据，我们将说明相关限制或引导您通过平台渠道提出请求。

8. 本政策如何变更

我们可能因游戏功能调整、服务提供方变化或法律法规要求更新本政策。更新后会在本页面标明新的更新日期；对于对您权益产生重大影响的变更，我们将通过网站公告、游戏内提示或其他适当方式告知，并根据适用规则在必要时重新取得同意。

建议您在游戏版本或功能发生明显变化时查阅本页面，以了解最新的信息处理规则。
