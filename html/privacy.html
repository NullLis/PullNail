🔒 隐私政策

PullNail《拔钉子》尊重并重视您的隐私。本政策说明我们如何处理、使用和保护相关信息。

最后更新日期：2026年11月5日

引言与适用范围

欢迎使用 PullNail《拔钉子》（以下简称“本游戏”）。本游戏由深圳市梦新技术工作室（个人独资）开发。本隐私政策适用于本游戏及其相关介绍、下载与支持网站（以下简称“相关网站”），用于说明我们及第三方服务提供方可能如何处理个人信息，以及您享有的相关权利。

本游戏以单机关卡玩法为主，您无需为体验基本单机玩法而主动提交姓名、手机号码等身份信息。 但本游戏已接入穿山甲广告 SDK，在广告服务启用时，该 SDK 可能按照本政策和其官方隐私政策处理设备标识、网络、广告交互等信息。 此外，远程配置获取、网站访问和问题反馈也可能涉及必要的信息处理。

我们遵循合法、正当、必要及透明原则处理个人信息。本政策不会替代第三方服务提供方自身的隐私政策。由于 SDK 版本、功能开关及系统环境可能影响实际采集字段，开发者应当持续核实并如实更新披露内容。

1. 我们可能收集的个人信息

根据您使用的功能以及本游戏实际启用的服务，可能涉及以下信息：

  • 本地游戏数据： 关卡进度、游戏设置及其他恢复游戏状态的数据可能存储在您的设备本地。本地存储不等于自动上传。
  • 网络访问与基础日志： 当本游戏检查远程配置、版本信息，或您访问相关网站时，网络连接及托管服务可能处理 IP 地址、访问时间、请求路径、浏览器或设备类型等信息，以完成网络请求和维护安全。
  • 广告 SDK 采集的信息： 本游戏已集成 穿山甲广告 SDK 。在广告相关功能启用后，该 SDK 可能自行采集设备品牌、型号、系统版本、屏幕密度和分辨率、设备语言及其他设备基础信息；Android ID、OAID 等设备标识符；IP 地址、运营商、Wi-Fi 状态、网络信号强度等网络信息；应用包名、版本号、应用前后台状态、运行中的进程信息；广告展示、点击、转化等交互数据；以及崩溃和性能诊断数据，用于广告投放、归因、反作弊和服务稳定性保障。
  • 按 SDK 版本与配置决定的可选信息： 针对 Android 设备，部分历史 SDK 版本或特定配置还可能涉及 IMEI、IMSI、设备 MAC 地址、MEID、ICCID 等设备标识，以及 GAID、Wi-Fi 网络标识（SSID、BSSID）、软件列表、传感器、粗略或精确位置信息等。这些字段并非当前版本必然采集；应以本游戏实际集成的 SDK 版本、隐私配置、系统权限及用户授权为准。
  • 主动提交的信息： 如果您通过邮件或 GitHub Issues 联系我们，我们可能处理您主动提供的邮箱地址、问题说明、截图及其他反馈资料，用于回应和解决问题。请勿在公开反馈页面发布敏感个人信息。

穿山甲广告 SDK 的最新信息类型、必选与可选项目详见其 官方隐私政策 。本政策列示的是该 SDK 在 Android 平台可能涉及的主要信息类别，最终应与 PullNail 当前安装包的实际配置保持一致。

2. 我们如何使用您的个人信息

我们及服务提供方可能在必要范围内将上述信息用于：

  • 提供本游戏的基本功能、远程配置获取和版本检查；
  • 通过穿山甲广告 SDK 加载、展示广告，统计展示与点击情况，开展广告监测归因、反作弊及效果分析；
  • 在启用相应功能且符合法律要求时开展个性化广告推荐；
  • 分析故障与性能问题，保障广告相关服务、游戏及相关网站的安全和稳定运行；
  • 回复您主动发送的咨询、反馈及隐私权利请求，以及履行适用法律义务。

穿山甲 SDK 对信息的具体处理目的、方式及范围，以其官方隐私政策和本游戏实际启用的功能为准。我们不会出售您直接向我们提交的个人信息，也不会将联系方式用于与反馈处理无关的营销。

3. 我们如何存储和保护您的个人信息

本地数据： 游戏进度和设置等本地数据通常存储在您的设备上，直到您清除相关数据或卸载游戏；实际情况可能受到系统备份功能影响。

网络及广告数据： 网站访问日志可能由 GitHub Pages、Cloudflare Pages 等提供方根据其规则处理和保存。穿山甲广告 SDK 自行采集的信息由其服务提供方依其隐私政策确定存储地点、保存期限及保护措施。有关广告信息保存和删除规则，请查阅 穿山甲广告 SDK 隐私政策 。

反馈数据： 对于您主动提供的咨询或反馈信息，我们仅在处理问题及履行必要义务所需的期限内保存，之后依法删除或进行适当处理。

我们会根据实际数据处理活动采取合理的传输保护、访问限制和最小必要措施，努力防止信息被未经授权访问、披露、篡改或丢失。但任何网络与存储技术都无法保证绝对安全。

4. 我们如何对外提供您的个人信息

我们不会以出售个人信息为目的向第三方提供您的数据。为向您提供相应服务，本游戏和相关网站涉及以下第三方服务：

穿山甲广告 SDK

  • SDK 名称： 穿山甲广告 SDK
  • 第三方名称： 北京巨量引擎网络技术有限公司
  • 个人信息范围：设备信息（品牌、型号、系统版本、屏幕分辨率、设备语言、时区、CPU 等）；设备标识（Android ID、OAID、支持设备上的 GAID，以及部分历史 SDK 版本或特定配置可能涉及的 IMEI、IMSI、设备 MAC 地址、MEID、ICCID 等）；网络信息（IP 地址、运营商、Wi-Fi 状态、网络信号强度，特定配置下的 SSID、BSSID）；应用信息（包名、版本号、运行进程、前后台状态及可选的应用列表）；可选位置信息（粗略位置、精确位置）；可选传感器信息；广告展示、点击及转化记录；崩溃及性能数据。具体字段取决于实际集成的 SDK 版本、配置、设备系统与授权情况。
  • 使用目的： 广告投放和展示、广告监测归因、效果统计分析、广告反作弊，以及稳定性保障；如果启用个性化推荐功能，还可能用于相关广告推荐。
  • SDK 隐私政策： 穿山甲广告 SDK 隐私政策
  • GitHub： 用于代码托管、GitHub Pages 网站及 GitHub Issues 反馈。参见 GitHub 隐私声明 。
  • Cloudflare： 用于网站及远程配置资源交付。参见 Cloudflare 隐私政策 。

除依法要求、取得必要授权或提供相关服务确有必要的情况外，我们不会随意转让或公开披露您的个人信息。第三方服务处理数据的具体规则，以其实际提供的服务及对应政策为准。

5. 我们如何使用Cookies及相关技术

Cookie 是网站可能存储在浏览器中的小型数据文件。目前，PullNail 相关网站页面不主动通过 Cookie 开展跨站广告追踪或个性化画像。浏览器及网站托管服务商仍可能使用 Cookie、缓存或其他必要技术维护安全、提供页面或保存相关设置。

本游戏中的穿山甲广告 SDK 不等同于网页 Cookie。它可能依据其技术实现使用设备标识、广告交互记录及类似技术开展广告展示、归因、反作弊和个性化推荐；具体处理方式详见 穿山甲广告 SDK 隐私政策 。

您可以通过浏览器设置清除或限制 Cookie；此操作不等于清除 Android 应用内的广告 SDK 数据或本地游戏存档。

6. 我们如何保护未成年人的权益

我们重视未成年人的个人信息保护。未成年人应在监护人指导下阅读本政策，并按照适用法律要求取得必要的监护人同意。

本游戏包含第三方广告服务。我们会根据适用法律及目标用户年龄要求配置广告相关功能，并采取适当措施保护未成年用户的个人信息。若涉及面向儿童提供广告服务，还需要遵守相应的儿童隐私及广告展示规则。

如监护人认为未成年人的个人信息被不当处理，可通过本政策第 9 章与我们联系。我们将核实并依法处理。

7. 您对个人信息享有的权利

在适用法律规定的范围内，您可能享有知情、访问、复制、更正、删除、限制或拒绝处理、撤回同意等权利。

  • 管理本地数据： 您可以通过系统设置清除应用数据或卸载游戏，但这可能使尚未备份的游戏进度无法恢复。
  • 管理主动提交的信息： 您可以联系我们申请查询、更正或删除您通过邮件提交的信息。通过 GitHub Issues 公开提交的信息可能受 GitHub 平台规则约束。

  • 撤回同意： 对于基于同意开展的处理活动，您可通过游戏提供的隐私管理途径或联系开发者提出撤回请求；撤回不影响此前依法进行的处理。

我们将核实您的请求并依据适用法律在合理期限内处理；需要第三方服务提供方配合的，我们将说明相应流程。
